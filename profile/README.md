# Lexmount

**Cloud browser infrastructure for AI agents.**

Lexmount builds browser infrastructure that helps AI agents access, understand, and operate the web at scale. Our work covers cloud browser sessions, browser automation protocols, structured page extraction, remote observation, replay, and browser-native tooling for agent workflows.

## Lexmount Browser Cloud

[Lexmount Browser](https://browser.lexmount.com/en) is our cloud browser platform for AI agents.

Create browser sessions on demand, run them in parallel, observe live execution, hand off to humans when needed, and preserve recordings for review and debugging.

Use Lexmount Browser when agents need:

- Elastic cloud browser capacity
- Parallel browser sessions
- Remote View and human takeover
- Session lifecycle management
- Credential and connection management
- Execution recording and replay
- Browser MCP and WebFetch MCP endpoints

**Start here:** [browser.lexmount.com](https://browser.lexmount.com/en)

## Moli

[Moli](https://github.com/lexmount/moli) is a powerful browser engine designed for AI agents.

It provides a structured-data-first browser runtime with real JavaScript, DOM, CSS state, storage, networking, automation protocols, and on-demand rendering. Moli is part of our broader work on making browsers more efficient, observable, and agent-ready.

## Why Lexmount

AI agents do not use browsers the same way humans do. They need to inspect pages, extract structured information, interact with forms and controls, run scripts, observe results, and scale across many sessions.

Lexmount provides the infrastructure layer for that workflow:

- Understand pages through DOM, Markdown, semantic trees, network data, and browser state
- Act through browser-native automation interfaces
- Observe live browser execution from a central control plane
- Replay sessions for debugging, review, and evaluation
- Scale browser workloads beyond local hardware limits
